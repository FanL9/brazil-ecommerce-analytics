# 阶段三 Member 3：流失用户分析报告

## 1. 分析目标

本模块围绕平台用户流失情况开展分析，主要回答以下问题：

1. 截至固定观察截止日，平台有多少用户满足行为型流失定义；
2. 流失用户与未流失用户在消费价值、复购行为及生命周期方面有何差异；
3. 两类用户在评论、配送等消费体验方面是否存在结构差异；
4. 支付方式、地域及工作日/周末消费结构是否与流失状态存在明显关联；
5. 首次购买时间与流失状态之间的关系在固定观察窗口下应如何解释。

本报告仅基于观察性历史交易数据描述用户群体差异和相关特征，不对用户流失原因作因果推断。
